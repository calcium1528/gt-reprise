# Reality
I am in absolute dismay with `timeline2.file`. I am not repeating the author's mistakes.

## Overview
Reality is the complete construct in which existence occurs. It consists of two fundamentally seperate components:
- The timeline, where time flows and existence progresses.
- The Void, which exists outside conventional space and time.

Changes to one may affect the other, and certain entities are capable of interacting with both.

A universe does not constitute a separate Reality. Multiple universes, if they exist, are contained within the same overall construct.

## Components

### Timeline
A timeline is a continuous sequence of events, generally of existence, making up a universe’s history.<br>
A SAVE file (aka. a file) is a save state of a timeline.

A timeline, in normal conditions, only ever has one SAVE file, and it is frequently updated over time.<br>
Multiple SAVE files of one timeline can exist, but having more than one file risks compromising the timeline's integrity.

Certain individuals with the Determination trait can interact with SAVE files through the SAVE, LOAD, and RESET functions.<br>
These functions do not necessarily affect everyone equally. Certain people may retain memories or awareness of previous versions of the timeline.

The one and only currently active timeline in Reprise is internally labeled as `file0`.<br>
An often discussed theory states that multiple timelines can exist at once, but no one has ever attempted to do so because of the possible multiversal interference implications. There has been no proof nor any counter-evidence made on this theory.

### Functions

#### SAVE
SAVE records the current state of the timeline at a specific point to a SAVE file. If one exists, it is normally overwritten (edge cases will soon be brought to light).

#### LOAD
LOAD restores the timeline to the state recorded by the current SAVE file.

#### RESET
RESET discards the current SAVE file and returns the timeline to an earlier state, while retaining certain information that is not stored within the SAVE.

### The Void
The Void is a dimension existing outside the boundaries of defined space and time. It does not possess a sequence of events of its own.

The Void lives independent of timelines and allows entities within it to observe events occurring within Reality.<br>
Being in the Void interferes with conventional timeline manipulation. Functions like SAVE, LOAD, and RESET cannot necessarily be used normally while within it.

## Anomalies
A timeline may become glitched when it is manipulated under abnormal circumstances. Such glitches can cause events, memories, or other aspects of reality to behave inconsistently.
